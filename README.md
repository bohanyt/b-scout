# B-Scout

**Turn raw footage into timestamped evidence for editors and AI agents.**

B-Scout is a local-first footage indexing project focused on short-lived visual context when speech is sparse. The experimental native-frame/regional CLI is under review on the existing implementation branch; it is not a production desktop analyzer.

## Principles

Preserve source timing and short-lived evidence; keep source media read-only; separate observations from OCR/editorial interpretation; preserve repeated occurrences; keep raw user media private.

Project coordination, current development status and private runtime reports are maintained in the owner workspace. This repository contains source, reproducible test inputs and public documentation.

Independent repository, not a fork. Repository material is MIT-licensed; third-party software/model/media licensing remains separate.
